# netmech 0.1.0

Falsification-tested estimators for **accumulation** (stability association) and **advection** (wind-dependent directional coupling) signatures in multi-station air-monitoring networks, with finite-shift permutation inference, family-wise control, decision rules and an exact composition decomposition. Extracted from the WBEA methane study (EMS manuscript in preparation). The core modules are mechanical copies of the frozen project code (`protocol-freeze`), regenerated by `build_from_frozen.py`.

## Install
```
pip install -e .            # from software/netmech
pip install -e .[test]      # with pytest
```
Requires Python >= 3.10, numpy, pandas, scipy (reference versions in `requirements-lock.txt`).

## Quick start
```
python examples/demo.py
```
Builds a synthetic 6-station network with a known stability coefficient (0.05 ppm/SD) and an advected tracer, recovers the stability association, detects directional coupling with all admissible whole-day wind shifts, and repeats the run without advection as a control.

## Modules
| Module | Content |
|---|---|
| `netmech.h2` | leave-pair-out residuals, pair wind, aligned/reversed hour sets, kernel weights, directional contrast D |
| `netmech.e08` | finite-shift p-values, max-T, pooled inverse-null-variance weighting, lag centroids and ordered-trend rule, stability association with next-day negative control, Kitagawa composition with fixed merges and joint bootstrap |
| `netmech.geometry` | distances, bearings, pair tables for arbitrary coordinates |
| `netmech.synthetic` | demonstration network with known mechanisms |

## Operating assumptions (summary)
Hourly data; co-located wind; station spacing giving transit times of about 0.5-3 h; approximately exchangeable whole-day wind shifts; thresholds stable relative to background for composition analyses. D tests coupling compatible with transport; it does not estimate transport speed, pathways or emissions.
