# Data restrictions
- This package contains **no WBEA monitoring data**. All examples use synthetic data generated by `netmech.synthetic`.
- WBEA continuous-monitoring exports are marked "For authorized use only". They must not be redistributed with this package or its repository. Users obtain them directly from WBEA (wbea.org, Data > Continuous Monitoring Data) under WBEA's terms.
- ERA5 reanalysis (Copernicus Climate Data Store) and NASA FIRMS products are subject to their providers' licences and are not distributed here.
- The WBEA project repository records SHA-256 checksums of all source files so that results can be reproduced from independently obtained copies.
